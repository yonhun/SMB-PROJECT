# 📌 Smart Mobility Design Project

🚗 **Xycar Autonomous Driving**

---

Welcome to the Xycar Project! This project involves an autonomous driving system for the XYCar using ROS, OpenCV, and various sensors. The main functionalities include line tracking, obstacle avoidance, tunnel navigation, and traffic signal detection.

## 📖 Introduction

This project utilizes a combination of camera and LIDAR data to navigate the XYCar. It implements various driving modes including line tracking, obstacle avoidance, and tunnel driving, all controlled by a PID controller.

## ✨ Features

- **Line Tracking**: Using camera input to follow road lines.
- **Obstacle Avoidance**: Utilizing LIDAR data to detect and avoid obstacles.
- **Tunnel Navigation**: Special mode for driving through tunnels.
- **Traffic Signal Detection**: Identifying and responding to traffic lights and AR tags.
